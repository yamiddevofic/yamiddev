# Usuarios afectados y cómo hacen uso de la solución
----
### Usuario 1 — Cliente potencial

|Aspecto|Detalle|¿Por qué?|
|---|---|---|
|**Rol**|Dueño de negocio que llegó por recomendación, redes o búsqueda en Google/IA||
|**Nivel técnico**|Bajo|No sabe cómo se hace, solo sabe lo que necesita|
|**¿Cómo le afecta el problema?**|No encuentra prueba sola — tiene que escribirte sin saber si vale la pena, o simplemente se va||
|**Nivel de afectación**|🔴 Alto|Es el primer filtro — si no se convence solo, no hay cliente|
|**Nivel de importancia del problema**|🔴 Alto|Es el usuario con más probabilidad real de convertirse en cliente|
|**¿Dónde lo usa?**|Celular, en el momento en que llega a tu contacto||
|**¿Con qué dispositivo?**|Celular principalmente||
|**¿Con qué internet?**|Variable||
|**¿Con qué frecuencia?**|Una sola vez||
|**¿Con qué estado mental?**|Ocupado, impaciente, evaluando varias opciones||

### Usuario 2 — Ya te escribió

|Aspecto|Detalle|¿Por qué?|
|---|---|---|
|**Rol**|Ya inició conversación pero quiere verificar tu trabajo antes de comprometerse||
|**Nivel técnico**|Bajo a medio|Tiene más contexto que el anterior pero sigue sin saber de código|
|**¿Cómo le afecta el problema?**|Tiene que pedirte ejemplos — agrega fricción a la negociación||
|**Nivel de afectación**|🟡 Medio|Ya tiene intención, pero la falta de prueba puede frenar el cierre|
|**Nivel de importancia del problema**|🟡 Medio|El problema lo ralentiza pero no lo bloquea completamente|
|**¿Dónde lo usa?**|Cualquier dispositivo, con más calma||
|**¿Con qué dispositivo?**|Cualquiera||
|**¿Con qué internet?**|Buena conexión||
|**¿Con qué frecuencia?**|Una o dos veces durante la negociación||
|**¿Con qué estado mental?**|Enfocado — ya tiene intención, solo necesita confirmación||

### Usuario 3 — Contacto técnico

|Aspecto|Detalle|¿Por qué?|
|---|---|---|
|**Rol**|Dev senior, CTO o colaborador que evalúa tu nivel técnico para contratarte o trabajar contigo||
|**Nivel técnico**|Alto|Lee código, entiende arquitectura y evalúa decisiones técnicas|
|**¿Cómo le afecta el problema?**|No puede evaluar arquitectura ni decisiones sin que tú se las expliques||
|**Nivel de afectación**|🟡 Medio|Tiene más paciencia que un cliente, pero la falta de prueba genera duda sobre tu seriedad|
|**Nivel de importancia del problema**|🟡 Medio|No es el usuario prioritario del MVP pero abre puertas a proyectos más grandes|
|**¿Dónde lo usa?**|Computador, con calma||
|**¿Con qué dispositivo?**|Desktop||
|**¿Con qué internet?**|Buena conexión||
|**¿Con qué frecuencia?**|Una vez, durante el proceso de evaluación||
|**¿Con qué estado mental?**|Enfocado, técnico, buscando detalles específicos||

### Usuario 4 — Curioso

|Aspecto|Detalle|¿Por qué?|
|---|---|---|
|**Rol**|Llegó por redes o recomendación casual sin intención clara de contratar||
|**Nivel técnico**|Variable|Puede ser cualquier perfil — no hay patrón definido|
|**¿Cómo le afecta el problema?**|No encuentra nada concreto — se va sin dejar rastro||
|**Nivel de afectación**|🟢 Bajo|No tiene intención de contratar, el problema no le genera una pérdida real|
|**Nivel de importancia del problema**|🟢 Bajo|No es un canal directo de clientes — puede convertirse en uno a futuro pero no es prioritario|
|**¿Dónde lo usa?**|Celular, en cualquier momento||
|**¿Con qué dispositivo?**|Celular principalmente||
|**¿Con qué internet?**|Variable||
|**¿Con qué frecuencia?**|Una sola vez, por impulso||
|**¿Con qué estado mental?**|Sin prisa, explorando, sin compromiso||

### Usuario 5 — Contratista de empresa

| Aspecto                               | Detalle                                                                                   | ¿Por qué?                                                                           |
| ------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Rol**                               | Persona dentro de una empresa que busca un dev externo para un proyecto puntual           |                                                                                     |
| **Nivel técnico**                     | Medio                                                                                     | Sabe lo que necesita pero evalúa según criterios de su empresa, no solo los propios |
| **¿Cómo le afecta el problema?**      | No puede presentarte internamente sin evidencia concreta que mostrarle a su jefe o equipo |                                                                                     |
| **Nivel de afectación**               | 🔴 Alto                                                                                   | Si no puede justificarte fácilmente ante su empresa, elige a alguien más conocido   |
| **Nivel de importancia del problema** | 🔴 Alto                                                                                   | Es un canal de acceso a proyectos más grandes y estables                            |
| **¿Dónde lo usa?**                    | Computador, en horario laboral                                                            |                                                                                     |
| **¿Con qué dispositivo?**             | Desktop principalmente                                                                    |                                                                                     |
| **¿Con qué internet?**                | Buena conexión                                                                            |                                                                                     |
| **¿Con qué frecuencia?**              | Una o dos veces durante la evaluación interna                                             |                                                                                     |
| **¿Con qué estado mental?**           | Cauteloso — necesita cubrirse ante su equipo, no solo convencerse él                      |                                                                                     |

### Usuario 6 — Yamid

| Aspecto                               | Detalle                                                                                   | ¿Por qué?                                                                        |
| ------------------------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **Rol**                               | Construye, actualiza y hoy explica manualmente su trabajo (por chat) en cada conversación |                                                                                  |
| **Nivel técnico**                     | Alto                                                                                      | Es el propio dev — conoce todo el sistema por dentro                             |
| **¿Cómo le afecta el problema?**      | Pierde tiempo repitiendo lo mismo en WhatsApp, llamadas y DMs sin garantía de convencer   |                                                                                  |
| **Nivel de afectación**               | 🔴 Alto                                                                                   | El costo no es visible pero es constante y acumulativo                           |
| **Nivel de importancia del problema** | 🔴 Alto                                                                                   | Es el único que puede resolverlo y el que más tiene que ganar cuando se resuelve |
| **¿Dónde lo usa?**                    | Computador, en Chitagá                                                                    |                                                                                  |
| **¿Con qué dispositivo?**             | Desktop                                                                                   |                                                                                  |
| **¿Con qué internet?**                | Buena conexión                                                                            |                                                                                  |
| **¿Con qué frecuencia?**              | Cada vez que termina un proyecto o quiere mejorar algo                                    |                                                                                  |
| **¿Con qué estado mental?**           | Tranquilo, en modo creativo o técnico                                                     |                                                                                  |
