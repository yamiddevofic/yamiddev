# Migración y datos 
## ¿El cliente tiene un sistema viejo? 
Sí, hay un portafolio de antes.

##  ¿Hay que migrar un Excel, una base de datos antigua o integrar datos de producción existentes? 
No hay base de datos ni Excel que migrar. El contenido del portafolio viejo (proyectos, textos, imágenes) se rescribe desde cero en el nuevo.
