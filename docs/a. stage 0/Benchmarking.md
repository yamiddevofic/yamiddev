# Comparativa de mercado (Benchmarking)
### Portafolio #1 — [Brittany Chiang Portolio](https://brittanychiang.com)

| Aspecto                  | Observación                                                                                                                                                                                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stack / Tecnología**   | NextJS, TailwindCSS, PWA, Open Graph                                                                                                                                                                                                                             |
| **Estilo visual**        | Minimalista y moderno                                                                                                                                                                                                                                            |
| **Primera impresión**    | No tiene foto, es interesante como coloca todo el contenido en la parte derecha con scroll, y la izquierda totalmente inmovil (fija), animaciones interesantes, y el espaciado del contenido que permite respirar el contenido, tiene como una simetría perfecta |
| **Especialidad visible** | Interfaces de usuario minimalistas, modernas y con efectos de animación de scroll                                                                                                                                                                                |
| **Proyectos**            | Sí, muestra contexto de negocio en los proyectos porque al presionar lleva al sitio en vivo                                                                                                                                                                      |
| **Contacto**             | Para otros desarrolladores sí es claro, o gente que sabe de tecnología, pero para alguien de otro negocio no sé si sea totalmente claro.                                                                                                                         |
| **Lo que hace bien**     | Utilizar bien el scroll y efectos de scroll, así como el uso del espacio                                                                                                                                                                                         |
| **Lo que le falta**      | Color, internacionalización                                                                                                                                                                                                                                      |
| **Qué puedo tomar**      | Diseño en desktop                                                                                                                                                                                                                                                |

### Portafolio #2 — [Max Block Portfolio](https://mxb.dev)

| Aspecto                  | Observación                                                                                                                                                                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Stack / Tecnología**   | PWA                                                                                                                                                                                                                                  |
| **Estilo visual**        | Accesible, minimalista, personalizable                                                                                                                                                                                               |
| **Primera impresión**    | Minimalista, enfocada en lo importante, vinculada a redes sociales como X.                                                                                                                                                           |
| **Especialidad visible** | Accesibilidad, personalización, Escritura                                                                                                                                                                                            |
| **Proyectos**            | Mayormente de escritura, y participación en la comunidad. Su negocio es Codista, un SaaS. Pero sí se ve que su negocio es la web                                                                                                     |
| **Contacto**             | No, se enfoca en su posts de su blog web.                                                                                                                                                                                            |
| **Lo que hace bien**     | Persoanlización de paleta de colores, letra y colores legibles, minimalista, incorporar su blog como parte importante de su web                                                                                                      |
| **Lo que le falta**      | Acceso rápido al perfil de Max desde home, internacionalización, mostrar su recorrido como profesional                                                                                                                               |
| **Qué puedo tomar**      | Personalización de paleta de colores, el header, estilo de los posts destacados en home cuando cree posts, cómo organizar el contenido de los posts en el blog, y cada post individualmente, sistema de comentarios, y calificación. |
